# Eita! 

This is my monorepo for various experiments and toy projects where I explore modern AI techniques and technologies.
My intention with this repository is to try out different models, explore techniques such as building small agentic AI prototypes, RAG systems, MCP servers while exploring more protocols other than MCP.

## When using Ollama

Running a text based chat with llama3.2:1b model

```
ollama run llama3.2:1b
```

## Prototypes

- **ollama-simple-generic**: A script that sends a single prompt to the Ollama API and prints the response.
- **ollama-simple-agent**: A simple agent built on top of Ollama LLMs that can answer questions about some people's birthdays.
