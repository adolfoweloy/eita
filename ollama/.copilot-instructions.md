# GitHub Copilot Instructions

## Project Context
This project focuses on working with Ollama API for local AI model interactions.

## Coding Preferences
- Use Python for API interactions
- Prefer the `requests` library for HTTP calls
- Handle streaming JSON responses properly (Ollama returns newline-delimited JSON)
- Always include proper error handling for API responses
- Write clean, readable code with meaningful variable names
- Always add imports at the top of the file

## API Guidelines
- Ollama API endpoint: `http://localhost:11434/api/generate`
- Response format: Streaming JSON objects, one per line
- Each JSON object contains a `response` field with generated text tokens
- Final object has `"done": true` and includes metadata
- Always concatenate response pieces to build complete answers

## Code Style
- Use clear variable names
- Include comments for complex logic
- Handle exceptions gracefully
- Prefer explicit error checking over silent failures

## Dependencies
- `requests` library for HTTP operations
- Built-in `json` module for parsing responses
